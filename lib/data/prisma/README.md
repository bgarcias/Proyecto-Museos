# Implementación con Prisma

Aquí irá la implementación de la capa de datos con Prisma y PostgreSQL (Supabase).

Debe cumplir los mismos contratos que `lib/data/memoria`, definidos en `lib/data/contratos.ts`. Cuando esté lista, se activa con `DATA_SOURCE=prisma`. Los pasos están en `docs/CONEXION.md`.
